01 / THE PROBLEM

A simple moment can become a serious safety risk.

Children can sometimes be unintentionally left inside a vehicle. In a closed vehicle exposed to hot weather, cabin temperature can rise quickly. THERMOGUARD focuses on early temperature monitoring and warning.

☀

Rapid Heat

A closed vehicle can become very hot when exposed to direct sunlight and hot weather.

⚠

Safety Risk

High cabin temperature can create a dangerous environment, especially for children.

🔔

Need for Warning

An automatic warning system can help draw attention when temperature reaches a set threshold.

02 / OUR SOLUTION

Meet THERMOGUARD.

Instead of only displaying temperature, the system uses temperature data to trigger an action. At the selected threshold of 35°C, the servo changes the vent position and the buzzer provides an alert.

01MonitorAHT20 continuously reads cabin temperature.
02RespondRaspberry Pi Pico processes the sensor data.
03VentilateServo automatically controls the vent position.
04WarnBuzzer and web dashboard show the system status.
