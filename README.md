# THERMOGUARD

Smart Vehicle Heat Monitoring & Warning System.

## GitHub Pages
1. Create a new public GitHub repository, e.g. `thermoguard`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the website URL.

## Custom images
Put project photos inside `images/` and update the image sections in `index.html` when ready.
