THERMOGUARD
Smart Vehicle Heat Monitoring & Warning System.
GitHub Pages
Create a new public GitHub repository, e.g. `thermoguard`.
Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select `main` and `/ (root)`, then save.
GitHub will provide the website URL.
Custom images
Put project photos inside `images/` and update the image sections in `index.html` when ready.
